# إذاعة البحرين - Radio Bahrain

صفحة هبوط عصرية لإذاعة البحرين - Modern landing page for Radio Bahrain

## نظرة عامة - Overview

This repository contains a modern, Arabic-language landing page for Radio Bahrain, featuring:

- 🎨 **Modern Design**: Beautiful gradient backgrounds with smooth animations
- 🇧🇭 **Arabic First**: Right-to-left layout with Tajawal font
- 📱 **Responsive**: Works perfectly on all devices
- ⚡ **Fast**: Pure HTML/CSS with no dependencies
- 🎙️ **Radio Theme**: Animated radio waves and broadcasting elements

## مشاهدة الصفحة - View Page

Visit the live page at: [https://radiobahrain.github.io/RadioBahrain/](https://radiobahrain.github.io/RadioBahrain/)

## الميزات - Features

- **بث مباشر** - Live broadcasting section
- **موسيقى متنوعة** - Diverse music showcase
- **أخبار محلية** - Local news coverage
- **روابط التواصل الاجتماعي** - Social media links
- **تصميم متجاوب** - Mobile-responsive design

## التقنيات المستخدمة - Technologies

- HTML5
- CSS3 (Animations, Gradients, Flexbox, Grid)
- Tajawal Font (Google Fonts)
- RTL (Right-to-Left) Layout
